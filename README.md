# SGH
- **Vitals** – heart rate and SpO2 from the Samsung built-in sensor, plus sensor-light toggles (red / IR emitters).
- **GPS** – expandable cards (fix, position, speed, altitude and pressure, compass, satellites, online place and weather) and a satellite finder that rotates with the compass.
- **Cells** – serving and neighbouring cell towers, tower radar, tower location through OpenCelliD (free API key needed).
- **Motion** – accelerometer, gyroscope, magnetometer graphs and a G-force card with a raw-data tab.
